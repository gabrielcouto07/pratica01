Tecnologia no dia a dia

A tecnologia já faz parte de quase tudo na nossa rotina. A gente usa para estudar, conversar com os amigos, trabalhar e até para pedir comida quando bate aquela preguiça.

O que eu mais gosto nessa área é que sempre aparece alguma coisa nova para aprender. No começo alguns códigos parecem difíceis, mas depois que funcionam dá uma satisfação enorme.

Quero continuar aprendendo desenvolvimento Web para conseguir criar projetos cada vez melhores. Ainda tenho muito pela frente, mas cada atividade já ajuda a entender um pouco mais.
